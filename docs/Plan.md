## 사이클 3 — 스페어 보너스

**검증할 동작:** 스페어 후 다음 투구 점수가 보너스로 더해진다

**테스트 메서드명:** `oneSpare`
**DisplayName:** "스페어 후 다음 투구 점수가 보너스로 더해진다"

**Given:**
- 1프레임: roll(5), roll(5) → spare
- 2프레임: roll(3), 이후 17구 roll(0)

**When:** score() 호출

**Then:** 16 반환
- 1프레임: 10 + 보너스(3) = 13
- 2프레임: 3
- 나머지: 0
- 합계: 16

**예상 실패 이유:** 현재 score()는 단순 합산(13 반환). 보너스 로직 없어 16이 아닌 13 반환.

**필요한 구현 변경:**
- score()를 프레임 단위 루프로 교체
- spare 조건 추가 (두 투구 합 == 10)
- rollIndex로 투구 위치 추적
