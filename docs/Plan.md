## 사이클 4 — 스트라이크 보너스

**검증할 동작:** 스트라이크 후 다음 두 투구 점수가 보너스로 더해진다

**테스트 메서드명:** `oneStrike`
**DisplayName:** "스트라이크 후 다음 두 투구 점수가 보너스로 더해진다"

**Given:**
- 1프레임: roll(10) → strike (1회 투구로 프레임 종료)
- 2프레임: roll(3), roll(4)
- 이후 16구: roll(0)

**When:** score() 호출

**Then:** 24 반환
- 1프레임: 10 + 보너스(3+4) = 17
- 2프레임: 3 + 4 = 7
- 나머지: 0
- 합계: 24

**예상 실패 이유:**
현재 spare 조건 `rolls[i] + rolls[i+1] == 10`이 스트라이크(10+0=10)도 잡아버림.
rollIndex +2 이동 → 1프레임을 2구로 처리 → 점수 계산 오류.

**필요한 구현 변경:**
- strike 조건 추가 (`rolls[rollIndex] == 10`)
- strike 시 rollIndex +1 이동 (1구만 소비)
- strike 보너스 = 다음 2구 합산
